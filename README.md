> 面向考研及长期备考用户的本地优先学习专注工具，覆盖计划、专注、统计和复盘。

## 功能

### 可靠专注计时

- 25、45、60、90 分钟固定倒计时。
- 支持灵活正计时，从 00:00 开始，可随时暂停、结束并按实际时长记录。
- 灵活计时与标准专注分开统计，不会增加标准专注段数量或触发休息周期。
- 开始、暂停、恢复、重置与放弃。
- 按真实结束时间校正后台和锁屏期间的倒计时。
- 保存进行中的会话，应用重新启动后可恢复。
- 支持短休息、长休息和下一轮专注。
- 严苛模式会在放弃专注前进行二次确认。
- 计时结束支持本地通知和震动反馈。

### 费曼学习（文字版）

- 学习单元分为“输入理解”和“费曼输出”两段，默认 20/10 分钟。
- 输出计划时长不得低于输入时长的 50%，避免只输入不输出。
- 输入阶段结束后进入输出准备，输出阶段支持文字讲解草稿自动保存与重启恢复。
- 输出倒计时结束后可继续讲解并记录超时时间，不会强制截断。
- 讲解过程中可即时标记“卡壳”，记录阶段时间戳、关键词、原因、备注和严重程度。
- 提供按章节聚合的卡点热力排行，并可标记卡点是否解决。
- 复盘支持“已讲清楚、仍有盲点、需要重读”，系统会根据输出比例和卡点情况给出重读建议。
- 当前版本仅实现文字讲解，暂不包含录音、麦克风权限和音频存储。

### 日历规划与每日目标

- 全中文月历视图，左右滑动切换月份，有任务的日期显示圆点标记。
- 支持任意日期规划，点击日期即可查看和管理当天任务。
- 每日目标设定：为任意日期设置目标专注段数，未单独设置时使用全局默认值，进度条实时展示完成情况。
- 支持政治、英语、数学、专业课和其他分类。
- 支持新增、编辑、完成、删除和延期任务。
- 支持优先级、备注和预计专注段数。
- 根据专注记录展示任务实际完成的专注段数。
- 历史任务会被保留，不会在次日自动删除。

### 氛围音

- 自行导入本地音频文件作为氛围音（雨声、白噪音等），不内置素材，保持安装包小巧。
- 支持选择播放与音量调节，可开启专注时自动播放、休息和结束后停止。

### 统计与历史

- 日、周、月三个统计维度。
- 专注时长、专注段数、趋势图、学科占比和近一年学习日历热力图。
- 最近专注记录及完整历史记录页面。
- 支持删除单条专注记录，并同步更新统计数据。

### 院校（排名与专业代码）

- 内置软科中国大学排名主榜（2026 年 590 所），完全离线可用。
- 按校名实时搜索，支持省份、院校类型和双一流/985/211 标签筛选，筛选后即时显示命中数量。
- 列表展示名次、校名、标签、省市、类型与总分。
- 内置教育部《研究生教育学科专业目录（2022 年版）》：14 个学科门类、117 个一级学科、67 个专业学位类别，可按门类浏览。
- 专业代码支持按代码或名称搜索（如 0812 / 计算机），标注一级学科与专业学位（含是否可授博士）及可授学位门类注释。
- 排名卡片一键星标收藏意向院校，"意向"标签查看全部收藏。
- 目标面板：设置目标院校后，专注页顶部常驻轻量目标提醒（目标院校 · 距考研天数 · 今日专注分钟），点击直达院校页。
- 择校倒计时默认按"12 月倒数第二个周六"自动推算考研初试日，可手动调整为任意日期；支持自定义里程碑（标题 + 可选日期）记录报名、模考等备考节点。
- 每年软科发布新榜后，运行 `dart run tool/fetch_bcur.dart` 更新排名数据并随版本发布。

**数据时效性说明**：院校排名与专业代码均为应用内置的静态数据，具有时效性——排名对应软科 2026 年榜单（每年约 4 月更新），专业目录对应教育部 2022 年版（隔数年修订），应用内不会联网刷新。择校倒计时的考试日期为用户自设或按"12 月倒数第二个周六"自动推算，官方考试安排与各校招生时间请自行确认。上述数据仅供查询参考，请以官方最新发布为准，使用前请自行确认是否仍为最新版本；需要更新时重跑 `tool/` 下对应抓取脚本并随新版本发布。意向收藏与目标院校为本地个人数据，不参与备份导出。

### 应用内更新检查

- 启动时自动检查 GitHub 上的最新版本，设置页也可手动触发。
- 发现新版本后弹窗展示版本号、更新说明，支持"跳过此版本"和"立即更新"。
- 跳过的版本会持久化记录，后续手动检查时不受影响。

### 数据管理

- 导出版本化 JSON 备份并通过系统分享。
- 从本地 JSON 文件导入，导入前进行完整性校验。
- 导入失败时恢复原有数据。
- 支持清空全部任务和专注记录，并提供双重确认。
- 数据默认保存在本地，无需登录。

### 当前限制

- 费曼讲解目前仅支持文字版，录音功能暂未提供。
- 正式应用商店发布前仍需配置 Android 正式签名。

## 项目结构

```text
lib/
├── core/
│   ├── services/       # 通知、震动和数据备份
│   ├── theme/          # 主题与颜色
│   ├── utils/          # 通用工具
│   └── widgets/        # 通用组件（更新弹窗等）
├── data/
│   ├── models/         # Hive 数据模型
│   └── repositories/   # 本地数据仓库
├── providers/          # Riverpod 状态管理
├── router/             # 应用路由
└── views/
    ├── focus/          # 固定与灵活专注计时
    ├── feynman/        # 费曼学习、文字讲解、复盘和卡点热力图
    ├── plan/           # 日历规划与每日目标
    ├── stats/          # 日、周、月统计
    ├── college/        # 院校排名、专业代码与目标择校
    ├── history/        # 专注历史
    └── settings/       # 设置与数据管理

assets/data/            # 内置院校数据（排名 / 专业目录，tool/ 下脚本生成）
design/logo/            # 应用图标源文件与生成脚本
tool/                   # 开发期数据抓取脚本（软科排名 / 学科专业目录）
update/                 # 应用内更新版本描述文件
test/                   # 单元测试与 Widget 测试
.github/workflows/       # 持续集成
```

## 版本与数据兼容

- 应用版本以 `pubspec.yaml` 为唯一来源，设置页会在运行时读取版本号。
- Task 和 FocusSession 的 Hive 字段采用追加方式演进，现有本地数据可继续读取。
- 费曼学习单元与卡壳记录使用独立 Hive 数据盒。
- JSON 备份格式已升级为 v2，并继续兼容 v1 备份导入。
- 建议在升级或测试导入功能前先导出 JSON 备份。
